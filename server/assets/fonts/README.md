# PDF fonts

The order slip / invoice / statement PDFs are generated by `server/utils/pdf.js`.

By default they use pdfkit's built-in Helvetica, which is **Latin-only**. English
labels, digits and totals render correctly, but Bengali characters in a customer's
name, address or special note come out as mojibake.

To render Bangla, drop a Unicode TTF that covers Bengali into this folder. The first
match wins (see `FONT_CANDIDATES` in `server/utils/pdf.js`):

| File name                     | Notes                                              |
| ----------------------------- | -------------------------------------------------- |
| `NotoSansBengali-Regular.ttf` | plus optional `NotoSansBengali-Bold.ttf`. SIL OFL. |
| `NotoSans-Regular.ttf`        | plus optional `NotoSans-Bold.ttf`.                 |
| `Nirmala.ttf`                 | plus optional `NirmalaB.ttf`. Ships with Windows.  |
| `kalpurush.ttf`               | common free Bangla font.                           |

On this machine `C:\Windows\Fonts\kalpurush.ttf` is already installed, so:

    cp C:/Windows/Fonts/kalpurush.ttf server/assets/fonts/kalpurush.ttf

No code change or restart flag is needed — the font is picked up on server start.
Verified: dropping the font in embeds a subset (`FontFile2`) and still produces a
valid PDF. Check the conjunct shaping (e.g. ন্ড, and vowel signs such as ি) visually
before relying on it, and confirm the font's licence allows redistribution if you
commit it to the repository.
